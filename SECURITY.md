# Security Policy

## Unterstützte Versionen

Es wird jeweils nur die aktuellste veröffentlichte Version mit Sicherheitsupdates versorgt.

| Version | Unterstützt        |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Sicherheitslücke melden

Linux System Dashboard führt privilegierte Systemoperationen aus (Paketverwaltung, Firewall,
Terminal-Befehle), daher nehmen wir Sicherheitsmeldungen ernst.

**Bitte meldet Sicherheitslücken nicht über öffentliche GitHub-Issues.**

Stattdessen bitte über den privaten Meldeweg auf GitHub:
["Report a vulnerability"](https://github.com/Avacon00/linux-system-dashboard/security/advisories/new)
im Security-Tab des Repositories, oder alternativ per E-Mail an den Maintainer (siehe GitHub-Profil).

Bitte in der Meldung enthalten:
- Betroffene Version(en)
- Eine Beschreibung der Schwachstelle und ihres potenziellen Impacts
- Schritte zur Reproduktion (falls möglich)

Wir bemühen uns, innerhalb von 7 Tagen auf Meldungen zu reagieren.
